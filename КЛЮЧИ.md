# Куда вставить ключи (3 минуты)

SpyTrend уже настроен. Нужны только **3 ключа** — Higgsfield, Perplexity, fal.ai.

---

## Способ 1 — через сайт Cursor (самый простой, без файлов)

1. Открой: **[Secrets в Cursor → нажми сюда](https://cursor.com/dashboard/cloud-agents/environments/e/f054ebe8-9520-11f1-ba66-0e7d0216e441)**
2. Добавь три секрета (кнопка Add / New secret):

   | Имя | Где взять ключ |
   |-----|----------------|
   | `HF_KEY` | [cloud.higgsfield.ai](https://cloud.higgsfield.ai) → API Keys → формат `id:secret` |
   | `PERPLEXITY_API_KEY` | [perplexity.ai/settings/api](https://www.perplexity.ai/settings/api) → ключ `pplx-...` |
   | `FAL_KEY` | [fal.ai/dashboard](https://fal.ai/dashboard) → Keys |

3. Сохрани. Готово — агент подхватит сам.

> **Важно:** ключи из dashboard видны только **новому** агенту.  
> Если уже добавил ключи — нажми **New Agent** (новый чат) и напиши «проверь».

---

## Способ 2 — один файл в проекте (если работаешь локально на Mac)

1. Открой проект **gambing-creo-fabrica** в Cursor.
2. Нажми **Cmd + P** (поиск файла).
3. Напиши: **`.env`** → Enter.
4. Вставь ключи после знака `=`:

```
HF_KEY=сюда_higgsfield_id:secret
PERPLEXITY_API_KEY=сюда_pplx-ключ
FAL_KEY=сюда_fal_ключ
```

5. Сохрани (**Cmd + S**).

Шаблон (если файла `.env` нет): **[.env.example на GitHub](https://github.com/yehornwork-cmd/gambing-creo-fabrica/blob/main/.env.example)** — скопируй содержимое в новый файл `.env`.

---

## Где взять ключи

- Higgsfield: **[cloud.higgsfield.ai](https://cloud.higgsfield.ai)** → API Keys
- Perplexity: **[perplexity.ai/settings/api](https://www.perplexity.ai/settings/api)**
- fal.ai: **[fal.ai/dashboard](https://fal.ai/dashboard)** → Keys

---

## Проверка

Напиши агенту в чат: **«проверь ключи»** — он сам запустит проверку.
